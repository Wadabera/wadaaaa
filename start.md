# 🚀 Getting Started with Wada Abera Portfolio

## Quick Start

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Start Development Server**
   ```bash
   npm start
   ```

3. **Open in Browser**
   - The app will automatically open at `http://localhost:3000`

## Next Steps

### 1. Replace Images
- Replace `/images/_MYO3937.JPG` with your main profile photo
- Replace `/images/photo_WADA1.jpg` with your about section photo
- Add project screenshots to `/images/portfolio/`

### 2. Update Personal Information
- Edit contact details in `src/components/Contact.js`
- Update social media links throughout the components
- Modify the about section content in `src/components/About.js`

### 3. Add Your Projects
- Update the projects array in `src/components/Projects.js`
- Add your GitHub and demo links
- Include project screenshots

### 4. Customize Content
- Update skills and proficiency levels in `src/components/Skills.js`
- Modify services in `src/components/Services.js`
- Add real testimonials in `src/components/Testimonials.js`

## Build for Production

```bash
npm run build
```

## Deploy

The project is ready for deployment on:
- **Netlify**: Just drag and drop the `build` folder
- **Vercel**: Connect your GitHub repository
- **GitHub Pages**: Use the build folder
